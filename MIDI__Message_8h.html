Detailed Description

An optional header that defines a standard MIDI message data type.

To include from the sketch level, use:

#include <MIDI_Handler\MIDI_Message.h>
MIDI_Message.h
An optional header that defines a standard MIDI message data type.

Lots of frameworks provide some version of this so made a conscious decision not to tie the library to any specific one.
Can be used in conjunction with MIDI_Handler to implement a automatic handler mechanism for incoming MIDI data/events.
