Detailed Description

Class to manage a chain of shift registers outputs.

Currently utilizes the SPI bus to operate shift registers. Developed using 74HC585 shift registers, but should theoretically work for similar chips. TODO: Update to accept an SPI object so a different bus can be used. TODO: Update to allow straight shiftOut like usage. ◆ stopOutputs()

void IO_74HC595::stopOutputs ( )
overridevirtual

Stops each of the configured outputs on this IO.

Respects the shouldStop setting of each output. Outputs where shouldStop is true will be reset to their initial state (based on inverted setting). This is automatically called through the framework (see MIDI_Device_Controller::stopPlaying()).
