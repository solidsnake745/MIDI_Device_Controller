◆ stopOutputs()

virtual void IO_Device::stopOutputs ( )
pure virtual

Stops each of the configured outputs on this IO.

Respects the shouldStop setting of each output. Outputs where shouldStop is true will be reset to their initial state (based on inverted setting). This is automatically called through the framework (see MIDI_Device_Controller::stopPlaying()).

Implemented in IO_74HC595, and IO_DigitalWrite.
