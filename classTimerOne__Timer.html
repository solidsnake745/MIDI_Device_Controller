Detailed Description

Timer interrupt using the <TimerOne.h> library.

Compatible with Arduino AVR and Teensy boards.
Side note: The <TimerOne.h> library for AVR versus Teensy are actually two different versions.
One of which is included through Teensyduino and is prioritized in those cases.
