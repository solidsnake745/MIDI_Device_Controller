Detailed Description

A data class to represent a MIDI message.

Used to store MIDI data and help facilitate handling incoming events.
3 byte long messages consisting of status, data1, and data2.
Implementation based off of details from:
http://www.songstuff.com/recording/article/midi_message_format/
http://www.electronics.dit.ie/staff/tscarff/Music_technology/midi/midi_messages.htm

uint16_t MIDI_Message::getBendValue ( )
inline

Gets the pitch bend value of this message by combining data1 and data2.

Pitchbend data is a 14 bit value made up of data 1 and data 2.
MIDI data packets are 7 bits stored in a byte (8 bits).
The LSB is in data 1 and MSB in data 2.
Combine data by shifting the MSB 7 bits and adding the LSB.

Returns
Returns a value between 0 to 16838 per original MIDI data. Note that calculations are expecting -8192 to 8191.
